# B1 — The Glacier cost gotcha

What's the actual cost impact of an early deletion after archival? How would you redesign the
lifecycle so this stops quietly costing more than budgeted?

Day 0 - photo uploaded

Day 30 - moved to Glacier (90-days minimum starts)

Day 40 - seller asks for deletion, we delete 

=> 10 days used, billed 90 => pay for 80 unused days


## Redesign

- Option  1: move to Glacier later (day 120). Reduces the problem and doesn't remove it.
- Option 2: Intelligent-Tiering. No minimum period. Tiny Monitoring fees.
- Option 3: only archive files tagged archive_eligible=true

- Chose: option 2+3. Rejected option 1, because it only reduces the problem.
- Add a cost alert on early-delete charges
- The filter also fixes Terraform missing-files warning

```
rule {
    id     = "archive-sold-listing-photos"
    status = "Enabled"
    
    filter {
      and {
        tags                     = { archive_eligible = "true" }
        object_size_greater_than = 131072
      }
    }

    transition {
      days          = 30
      storage_class = "INTELLIGENT_TIERING"
    }
  }
```

## The actual cost impact

- Glacier has a 90 day minimum: 10 days used, 80 days still billed.
- Plus a fee per file moved, and around 40KB extra billed per file
- Archiving a photo deleted on day 40 costs more than not archiving it
